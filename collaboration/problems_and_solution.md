# 典型问题与修正方法

| 现象 | 定位方法 | 修正与可复用经验 |
|---|---|---|
| 相机已响应但没有完整帧 | 分开核对传感器、CSI、帧门控和 DMA 状态 | I²C 成功不能作为图像采集成功；按数据流逐层取得完整帧证据 |
| 图像质量/缩放方案的视觉判断不一致 | 固定输入、分离传感器合并与数字处理，分别送入识别 | 不把“看起来更平滑”等同于识别更准；保留处理阶段和尺度 |
| 并行优化提高某一指标却破坏旧结果 | 比较音高、起点、时值、声部及整页耗时，必要时交错测速 | 新增正确数与旧正确损失分别记；不以删音、强行凑拍或小样本替代回归 |
| 识别发布包与界面接口不一致 | 核对方向、尺寸、完成标记、进度事件和文件清单 | 显式约定生产者/消费者；模型与接口变更分别验收 |
| 曲库删后重现或写入权限错误 | 明确权威存储，核对完成记录、镜像、缓存和所有者 | 删除语义、原子写入及权限是接口的一部分 |
| 高分辨率界面响应或切换不稳定 | 分开测按键、状态查询、绘制与显示模式 | 保持可用版本，通过降低显示负载、后台等待和准备缓存改善响应 |
| 综合报告资源为零 | 检查 OOC IP 是否仍为黑盒，确认综合/布局/布线阶段 | 用完整链接后的设计导出报告；不能将空设计摘要作为通过证明 |
| 后期改动破坏音乐对齐或素材边界 | 以帧号、音轨包时间戳和关键帧核对 | 局部替换不自动顺延后续时间轴；原理动画与实机录屏分别说明 |

这些内容仅概括技术现象、验证方式和修正原则，不复述个人对话，也不提供模型内部推理。
