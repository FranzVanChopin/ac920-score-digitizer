### 3.3.5.2 技能包

本项目将大模型辅助开发中形成的有效经验整理到 `skill/` 目录，避免把协作成果仅保留为私人对话。技能来源覆盖 Claude 的识别算法与 C++ 加速工作，以及多个并行 Project 中的 FPGA 采集、符号关系优化、独立回归、系统集成、图像质量实验和宣传可视化制作。目录内的 README 统一说明各项技能的适用场景、使用入口、验证范围及失效条件；每个技能以 SKILL.md 为入口，并按需要附提示词工作流、交接模板、定位清单或只读校验脚本。

技能包共六项：FPGA 报告复核、MusicXML 语义回归、通用 PYNQ Overlay 文件预检、节拍时间轴编排、多工作线接口交接和隐私友好发布。报告复核针对 OOC 黑盒导致空资源统计、综合与实现阶段混用等问题；语义回归针对局部优化破坏音高、起点、时值和声部关系的问题；节拍编排针对修改局部镜头后音画错位的问题；交接与发布技能则将多工作线接口和隐私范围固化为可复用模板。

技能中的工具参数均由使用者输入，不绑定本题的相机型号、图像尺寸、特定寄存器地址或本机目录。只读脚本已用真实工程报告、生成的 MusicXML 和 Vivado 导出文件，以及等价、差异和异常输入进行验证；具体测试与范围记录在 `skill/VALIDATION.json`。多工作线模板完成本项目案例反填检查，尚未证明任意新团队都能直接迁移成功。

其中 PYNQ 技能依据官方 Overlay 的 bit/HWH 交接规则设计，可用于其他 Overlay 的同名文件、元数据、器件期望和地址范围检查，具有跨题目复用价值。但本项目当前部署并非 PYNQ 应用，该技能目前仅完成离线预检测试，未执行 PYNQ 实机下载、驱动、DMA 或功能验收，因此不把该部分表述为已完成的通用 PYNQ 部署成果或已获额外评分。

与直接公开聊天记录相比，这种组织方式保留了工程方法和可观察验证，去除了会话原文、个人路径和身份信息，也便于其他成员按任务选择单项技能复用。
