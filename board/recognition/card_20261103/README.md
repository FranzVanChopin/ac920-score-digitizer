# 当前卡上识别产物

本目录来自卡上 FAT 交换区的只读取回，不是本次重新运行识别。技术数据、逐页耗时和结果内容保留；本机位置和设备标识已尽量移除。

`Outputs/last_run.log` 记录六页的阶段进度、耗时及完成行；`album.json` 记录共七页相册状态，`00.musicxml` 与 `01.musicxml` 为两首实际生成结果。Meta 为拍摄参数。另有历史板端日志单独归档。

常驻流水线的逐页时间不能简单相加作为总墙钟时间；音符计数不代表准确率。Linux 系统 journal 不在本次取回范围。来源文件哈希与发布副本哈希可能因脱敏不同，交付校验以包根目录 MANIFEST.json 为准。
